# Claude Design 最初のプロンプト

Claude Design でプロジェクトを開始したら、以下の手順で進めてください。

---

## ステップ 1：プロジェクト作成時のアップロード

Claude Design の新規プロジェクト作成時に、以下を**すべて**添付してください。

1. **モバイル画面スクリーンショット 6枚**（`01_login.png` 〜 `06_stats.png`）
2. **デザインブリーフ**（`design-brief.md`）
3. **要件定義書**（`要件定義書.md`）← 別フォルダにある既存ファイル

※ 添付が多いと混乱する場合は、まずスクリーンショット6枚＋デザインブリーフだけで始めても可。

---

## ステップ 2：最初に送るチャットメッセージ（コピペ用）

以下を最初のメッセージとして送ってください。

---

```
「デジタル栞」というモバイルWebアプリのUIデザインをブラッシュアップしたいです。

## 前提
- 添付の6枚のPNGは、作成済みのモバイル画面モックアップ（390×844px、iOSスマホ想定）
- 添付のdesign-brief.mdにデザインコンセプト・タイポグラフィ・カラーパレット・各画面の意図をまとめてある
- 添付の要件定義書.mdに機能要件・データモデル・画面構成がある
- 最終的な実装スタックは Next.js + TypeScript + Tailwind CSS + Supabase
- このデザインは Claude Code にハンドオフして実装する

## デザインコンセプト（超要約）
「書籍のように静謐に」——
- 書影（本の表紙）以外はグレースケールに徹する（アクセント色なし）
- 和文明朝（Shippori Mincho）＋ 欧文セリフ（Cormorant Garamond）＋ ゴシック（Zen Kaku Gothic）の3書体
- 数字は大きく、余白は広く
- 温かみのある紙色（#F7F5EF）ベース

## 最初にお願いしたいこと
以下の順でお願いします。

1. **まず6枚の画面を見て、デザインの全体評価を率直に教えてください。**
   - 統一感、タイポグラフィ、余白、情報の優先順位などの観点で
   - 「ここは効いている」「ここは弱い／冗長／改善の余地がある」を指摘してほしい

2. **次に、各画面の1st版をキャンバスに再現・清書してください。**
   - 添付画像の意図とdesign-brief.mdを踏まえて
   - 単なる模写ではなく、一段磨いてほしい
   - 6画面すべて同じキャンバスに並べて表示

3. **再現後、以下3点について改善案を提示してください。**
   - (a) 余白・タイポグラフィの磨き込み
   - (b) 空状態（本が0冊・読書履歴が0件）の画面デザイン
   - (c) 画面遷移・インタラクションの提案（タップフィードバック、ローディング等）

まずは1の全体評価からお願いします。
```

---

## ステップ 3：想定される進め方

Claude Design との会話はおおよそこのような流れを想定：

1. **全体評価** — Claude Design から改善ポイントの指摘をもらう
2. **1st版の再現** — キャンバス上で6画面が清書される
3. **インライン編集で反復** — 「ここの余白をもう少し」「フォントサイズを大きく」など、画面上の要素を直接タップして指示
4. **バリエーションの生成** — 空状態、ダークモード、長文ケースなど
5. **Claude Code へハンドオフ** — エクスポート機能から Claude Code に直接送信

## ステップ 4：反復時に使える指示フレーズ集

### 構造・レイアウト（チャットで指示）
- 「本棚画面の書影グリッドを2列版と3列版、両方見せて」
- 「読書中画面にダークモードとライトモードの両バージョンを作って」
- 「書籍詳細の情報ヒエラルキーを見直して、もっと"現在地"が伝わるように」

### 細部の修正（インラインコメントで指示）
- 「このボタンの文字間隔をもう少し広く」
- 「このカードの角丸をなくして直線的に」
- 「この数字をもっと大きく、周りの余白を増やして」

### 追加の要望
- 「オンボーディングフロー（4画面）を新規作成して」
- 「長いタイトルの本を登録したときの表示バリエーションを見せて」
- 「アプリアイコンのデザイン案を3つ出して」

---

## ステップ 5：完成したら

Claude Design のエクスポート機能で、**「Handoff to Claude Code」** を選択して、作成済みの `claude-code-実装指示書.md` と合わせて Claude Code に引き渡す。これで実装フェーズに入れる。
