# デジタル栞アプリ 要件定義書

## 1. プロジェクト概要

### 1.1 アプリ名（仮）
デジタル栞 / Digital Bookmark

### 1.2 目的
紙の本を読む際の「どこまで読んだか忘れる」という課題を解決し、アナログの本をデジタルの本棚として管理できるWebアプリケーションを提供する。

### 1.3 コンセプト
単なるページ記録ツールではなく、**「アナログの本をデジタル的な本棚にする」** 体験を提供する。書籍情報の自動取得、進捗可視化、読書時間計測を通じて、読書をより楽しく・継続しやすくする。

### 1.4 ターゲットユーザー
- 紙の本を読む習慣がある人
- 栞を忘れたり無くしたりしがちな人
- 自分の読書ペースや進捗を把握したい人
- 複数の本を並行して読む人

---

## 2. 提供範囲

### 2.1 プラットフォーム
- **第1フェーズ**: モバイルファーストなWebアプリケーション（スマホブラウザでの利用を主眼に置く）
- **第2フェーズ（将来）**: ネイティブスマホアプリへの展開

### 2.2 公開範囲
不特定多数のユーザー向けに公開する。ユーザー認証により各自のデータを保護する。

---

## 3. 機能要件

### 3.1 ユーザー認証
| 項目 | 内容 |
|------|------|
| サインアップ | メールアドレス＋パスワード |
| ログイン | メールアドレス＋パスワード |
| ログアウト | 任意のタイミングで可能 |
| データ保護 | ユーザーは自分のデータのみ閲覧・編集可能 |

### 3.2 書籍登録（書籍API連携）
| 項目 | 内容 |
|------|------|
| 検索 | タイトルで検索し、Google Books APIから候補を取得 |
| 自動取得情報 | 表紙画像、著者、総ページ数、出版社、ISBN、概要 |
| 手動登録 | APIで見つからない本は手動で情報入力も可能 |
| 編集 | 登録後に情報を修正可能（総ページ数の誤差対応など） |

### 3.3 本棚（ライブラリ）
| 項目 | 内容 |
|------|------|
| 一覧表示 | 表紙画像をグリッド形式で表示する「本棚」UI |
| フィルタ | ステータス別（読書中/読了/積読）に絞り込み |
| ソート | 登録日順、更新日順、タイトル順 |
| 詳細遷移 | 本をタップで詳細ページへ遷移 |

### 3.4 ステータス管理
3つのステータスで書籍を管理する。
- **読書中（Reading）**
- **読了（Finished）**
- **積読（To Read）**

ステータスはユーザーが任意のタイミングで変更可能。

### 3.5 ページ記録（デジタル栞）
| 項目 | 内容 |
|------|------|
| 現在ページの更新 | 本の詳細ページから現在のページ数を入力・更新 |
| 履歴 | いつ何ページまで読んだかの履歴を保存 |

### 3.6 進捗表示
| 項目 | 内容 |
|------|------|
| 進捗率 | `現在ページ ÷ 総ページ数` をパーセントで表示 |
| 残りページ数 | `総ページ数 - 現在ページ` |
| プログレスバー | 視覚的に進捗を表示 |

### 3.7 読書時間計測
| 項目 | 内容 |
|------|------|
| 計測開始 | 本の詳細ページの「読書開始」ボタンで計測開始 |
| 計測終了 | 「読書終了」ボタンで計測停止＆記録 |
| セッション記録 | 開始時刻、終了時刻、読んだページ範囲、経過時間を記録 |
| 本単体の累計時間 | その本を読んだ合計時間を表示 |
| 全体の累計時間 | ユーザーの全書籍の読書時間の合計を表示 |

### 3.8 読了予測（残り読了時間）
| 項目 | 内容 |
|------|------|
| 計算ロジック | その本の `(累計読書時間 ÷ 読んだページ数) × 残りページ数` |
| 表示条件 | 少なくとも1回以上の読書セッション記録がある場合 |
| 表示形式 | 「あと約 ○時間○分で読了」 |

### 3.9 日付記録
| 項目 | 内容 |
|------|------|
| 読み始め日 | ステータスが「積読→読書中」になったタイミングで自動記録 |
| 読了日 | ステータスが「読書中→読了」になったタイミングで自動記録 |

## 4. 非機能要件

### 4.1 UI/UX
- モバイルファースト（スマホでの操作を最優先）
- レスポンシブ対応（PCブラウザでも快適に使える）
- タップ操作中心、テキスト入力は最小限
- 本棚のビジュアル（表紙画像）を重視したデザイン

### 4.2 パフォーマンス
- 初回ロード3秒以内を目標
- 本棚の画像は遅延ロード

### 4.3 セキュリティ
- パスワードはハッシュ化して保存（Supabase Auth任せ）
- Row Level Security (RLS) でユーザー間のデータ分離を保証
- HTTPS通信必須

---

## 5. 技術スタック

| レイヤ | 採用技術 | 選定理由 |
|--------|----------|----------|
| フロントエンド | Next.js (App Router) + TypeScript | Reactベースで実績豊富、モバイル対応しやすい、将来のReact Native移植が容易 |
| スタイリング | Tailwind CSS | 本棚UIの構築が高速、モバイル対応も柔軟 |
| 認証・DB・ストレージ | Supabase | PostgreSQLベースのBaaS。認証・DB・画像ストレージが一括、RLSで安全 |
| 外部API | Google Books API | 無料・APIキー不要、日本語書籍対応 |
| ホスティング | Vercel | Next.jsと最適、GitHub連携で自動デプロイ |

## 6. データモデル（概要）

### 6.1 users（Supabase Authが管理）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | uuid | ユーザーID（PK） |
| email | string | メールアドレス |
| created_at | timestamp | 作成日時 |

### 6.2 books（ユーザーの蔵書）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | uuid | 書籍ID（PK） |
| user_id | uuid | 所有ユーザー（FK → users.id） |
| title | string | タイトル |
| author | string | 著者 |
| cover_url | string | 表紙画像URL |
| total_pages | int | 総ページ数 |
| current_page | int | 現在のページ |
| status | enum | reading / finished / to_read |
| isbn | string | ISBN（任意） |
| description | text | 概要（任意） |
| started_at | timestamp | 読み始めた日（任意） |
| finished_at | timestamp | 読了日（任意） |
| created_at | timestamp | 登録日時 |
| updated_at | timestamp | 更新日時 |

### 6.3 reading_sessions（読書セッション記録）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | uuid | セッションID（PK） |
| book_id | uuid | 対象書籍（FK → books.id） |
| user_id | uuid | ユーザー（FK → users.id） |
| started_at | timestamp | 開始時刻 |
| ended_at | timestamp | 終了時刻 |
| start_page | int | 開始時のページ |
| end_page | int | 終了時のページ |
| duration_seconds | int | 経過秒数 |

## 7. 画面構成

| # | 画面名 | 内容 |
|---|--------|------|
| 1 | サインアップ / ログイン | 認証画面 |
| 2 | 本棚（ホーム） | 登録書籍を表紙グリッドで一覧表示、ステータスフィルタ |
| 3 | 本を追加 | タイトル検索 → 候補一覧 → 選択して登録 |
| 4 | 書籍詳細 | 表紙・情報・進捗・読書開始ボタン・履歴 |
| 5 | 読書中画面 | タイマー表示・ページ入力・終了ボタン |
| 6 | 統計 | 全体の累計読書時間、読了冊数など |
| 7 | 設定 | アカウント情報、ログアウト |
