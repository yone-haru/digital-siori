# デジタル栞 — デザインブリーフ

このドキュメントは、Claude Design に投入する際のデザイン意図・方針をまとめたものです。
添付する6枚のモバイル画面スクリーンショット（01〜06）と併せて使用してください。

---

## 1. プロダクトの一行紹介

紙の本の「どこまで読んだか忘れる」を解決する、デジタル本棚アプリ。書籍APIで情報を自動取得し、進捗・読書時間・読了予測を静かに記録する。

## 2. デザインコンセプト

> **「書籍のように静謐に」**

読書体験と地続きの、紙のような温かみと、活字書籍のような品のあるタイポグラフィ。派手なUIや過剰な装飾を排し、"使っていることを意識させない" ミニマルさを目指す。ただし無機質にはしない。和書・洋書の装丁に流れる美意識を、モバイルUIに落とし込む。

### 3つの原則
1. **数字は大きく、余白は広く** — 進捗%や読書時間は、書籍のページ番号のように堂々と
2. **色はグレースケール中心、装飾は最小限** — 色は書影（本の表紙）にだけ任せる
3. **文章は明朝、UIはゴシック** — 読み物と操作を、書体で自然に分離

## 3. タイポグラフィ

| 役割 | フォント | 用途 |
|------|---------|------|
| **欧文ディスプレイ・数字** | Cormorant Garamond (Light / Regular) | 数字・英語見出し・ラベル。古典的で優雅なセリフ |
| **和文ディスプレイ** | Shippori Mincho (Medium / Semibold) | 書名・ページ見出し・コンセプト文 |
| **UI本文** | Zen Kaku Gothic New (Regular / Medium) | ボタン・補助文・通常テキスト |

### トラッキング（文字間隔）

- 英大文字ラベル (`label-tiny`)：0.25em — ゆったり、高級感
- 英字 UI テキスト：0.05〜0.15em
- 和文本文：デフォルト

## 4. カラーパレット（厳密にグレースケール＋紙色）

```
Ink        #0A0A0A  — 主要テキスト、ボタン、強調
Ink-2      #2A2A2A  — 見出し下レベル
Muted      #6E6B65  — 副次テキスト
Muted-2    #9A968F  — キャプション、無効状態
Line       #E3DFD6  — 罫線、区切り
Line-2     #EFEBE2  — 背景ブロック、プログレス未到達
Paper      #F7F5EF  — 画面背景（温かみのあるオフホワイト）
BG         #F0ECE2  — 外側ワークスペース（さらに温かい紙色）
```

**重要：アクセントカラーは使わない。** 色はすべて「本の表紙」（書影）だけから生まれる。UIは黒・グレー・紙色で構成する。これが「書籍らしさ」と「使っていることを意識させない静けさ」の両立につながる。

### 書影のカラートーン

書影は12色のパレットで、それぞれ深く・落ち着いた色味で構成されている。（#2B3A2E の森緑、#7C2B28 の深紅、#1B2A3A の濃紺など、文学書や文庫の装丁を思わせる色調）。サンプルデザインではこれをブロック塗りで表現しているが、実装では Google Books API から取得した実書影画像を使用する。

## 5. 空間設計

- **画面両端の余白**：28px（左右 px-7 相当）
- **セクション間の余白**：24〜32px
- **タッチターゲット**：44px 以上
- **行間**：和文は広めに、英文は引き締める

## 6. 書体の原則

- **iOS ステータスバー風の時刻・電波アイコンを上部に配置**（モバイルアプリであることを明示）
- **角丸は極控えめ**：ボタン・カードは 2px。モバイルシェル自体のみ 48px の大きな角丸
- **影は薄く**：モバイルシェルに柔らかな落ち影。書影には立体感のためごく薄い影
- **ボトムナビ**：3項目（LIBRARY / ADD / STATS）、小さな英字ラベル

## 7. 画面一覧と意図

| # | 画面 | 意図・ポイント |
|---|------|--------------|
| 01 | Log in / Sign up | 書籍の扉ページのような静けさ。「あなたの読書を、次のページへ。」というコピーで、本と地続きの体験を示す |
| 02 | Bookshelf (Home) | 書影グリッドを主役に。ステータスごとにセクション分け。進捗バーは細く、数字は控えめ |
| 03 | Book Detail | 進捗%の巨大な数字がヒーロー。残りページ・予測時間・累計時間など読書の"現在地"が一目でわかる |
| 04 | Reading Timer | 黒背景で没入感。経過時間を本のページ番号のように明朝で大きく。"読書中" のパルス表現 |
| 05 | Add Book / Search | シンプルな検索→結果リスト。各結果に書影サムネ・著者・年・ページ数 |
| 06 | Stats | 累計読書時間がヒーロー。4つの数字グリッド＋週間バーチャート。装飾より数字そのものを見せる |

## 8. Claude Design への改善依頼の方向性

このモックアップは**十分に完成度の高い叩き台**として機能する。Claude Design では以下のような方向でブラッシュアップを想定：

### 優先度：高
- **微細な余白・タイポグラフィの磨き込み** — 実機で見たときの読みやすさを追求
- **実データを想定した画面のバリエーション** — 空状態（本が0冊）、読了直後、長いタイトル時など
- **インタラクション/遷移の提案** — タップ時のフィードバック、画面遷移、ローディング状態

### 優先度：中
- **ダークモード版** — 04 の読書タイマー以外もダーク化
- **アクセシビリティ調整** — コントラスト比、タッチターゲットの妥当性
- **追加画面の生成** — アカウント設定、書籍編集、空のステート、オンボーディング

### 優先度：低（必要に応じて）
- モーションのアイデア（ページめくりのメタファーなど）
- アプリアイコンの提案

## 9. 実装スタック（参考）

デザインはそのまま Next.js (App Router) + TypeScript + Tailwind CSS で実装される想定。Supabase で認証・DB、Google Books API で書籍情報取得、Vercel にデプロイ。Claude Design の「Claude Code へのハンドオフ」でこのまま実装フェーズに渡せる。
